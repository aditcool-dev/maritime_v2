## 3. Critical scientific/provenance distinction

The spill polygon is **SYNTHETIC**, not a remote-sensing observation.

It was generated by `scripts/0_make_spill_observation.py` using a forward Lagrangian particle simulation.

What is real:
- release position/time derived from AIS evidence
- vessel tracks
- NOAA CO-OPS observed wind
- NOAA CO-OPS observed current

What is synthetic:
- the spill polygon geometry itself

The generated polygon uses:
- 3000 particles
- 120 s timestep
- 50 m initial scatter
- 0.025–0.035 windage
- 2.0 m²/s eddy diffusivity
- 80 m particle buffer
- RNG seed 20190510
- true simulated slick age: 3.0 h

**Never present the polygon as a real Sentinel/SAR observation.**

The website may describe it as a synthetic/forward-simulation spill observation used as a stand-in for the SAR front end.

## 5. Pipeline architecture

### Step 3 — Environmental data
`3_fetch_env_data.py`

Fetches/caches real NOAA CO-OPS wind/current data.

### Step 0 — Synthetic spill observation
`0_make_spill_observation.py`

Not part of the attribution pipeline. It creates the synthetic polygon from the known release for feasibility testing.

### Step 1 — Scene loading
`1_load_sar_scene.py`

Reads the spill GeoJSON and derives scene geometry such as centroid, area and elongation.

### Step 2 — AIS extraction
`2_fetch_ais_tracks.py`

Uses Marine Cadastre daily AIS archives and extracts vessel tracks for the case region/time window.

The processed result is:
`data/interim/ais_tracks.parquet`

### Step 4 — Backward drift
`4_backward_drift.py`

Backtracks the slick centroid using the vector-mean of observed current + wind drift over candidate ages.

Candidate ages:
- 0.5 h through 12.0 h
- every 0.5 h
- 24 candidate origins

Uncertainty heuristic:
`r = max(250 m, 0.25 × backtrack distance)`

This is explicitly a heuristic, **not a calibrated error model**.

### Step 5 — Candidate scoring
`5_score_candidates.py`

Scores vessels using four components:

| Component | Weight |
|---|---:|
| Proximity | 40% |
| Heading | 30% |
| Temporal | 20% |
| AIS continuity | 10% |

Scales:
- proximity e-fold = 1500 m
- temporal e-fold = 5400 s / 90 min
- AIS gap threshold = 1200 s
- AIS gap time window = 7200 s
- AIS gap range = 10000 m
- candidate cutoff = 25000 m

Each vessel effectively selects its own best candidate slick age.

### Ablation
`5_score_candidates.py --no-backtrack`

Tests what happens if backward drift is disabled and the origin is simply the slick centroid at observation time.

### Step 6 — Report
`6_report.py`

Produces:
- ranked candidate table
- evaluation against quarantined ground truth
- ablation comparison
- no-heading sensitivity
- map
- Markdown and JSON report

## 8. Ablation and sensitivity results

### No-backtrack ablation

Without backward drift:
- MR HAPPY ranks 1st at 0.5013
- VOYAGER drops to rank 307, score 0.2253
- ROSE BALSAM drops to rank 447, score 0.0649

This demonstrates that the backward-drift stage materially changes candidate ranking.

### No-heading sensitivity

With heading removed:
- ROSE BALSAM becomes rank 1 at 0.7927
- MATTHEW JAMES rank 2 at 0.7867
- PROVIDER rank 3 at 0.7771
- THOR rank 6 at 0.6389
- VOYAGER rank 15 at 0.5552

This is a sensitivity analysis only. The headline result uses the specified weights.

Important scene limitation:
- spill aspect ratio is only 1.25
- the code explicitly warns that the slick is nearly round
- therefore the elongation axis is poorly defined and the 30% heading sub-score is largely uninformative for this scene

The website should expose this caveat if it displays the heading score.
